# У Речушки — мобильное приложение

React Native + Expo-приложение, которое использует тот же бэкенд, что и сайт. Каталог, избранное, заказы, бонусы, отслеживание доставки и аналитика идут через те же Spring-сервисы (nginx `/api/*`). Навигация построена на React Navigation, **без Expo Router**.

## Возможности

- **Главная** —hero-баннер, категории и популярные товары из `/api/mobile/home`.
- **Каталог** — поиск с задержкой 350 мс, фильтр по категориям, постраничный вывод, карточки товаров.
- **Товар** — описание, состав/характеристики от мобильного шлюза, выбор количества, избранное.
- **Корзина и оформление** — локальная корзина, промокод, списание бонусов, адрес и способ оплаты.
  Сервер остаётся источником цены: итоговая сумма, скидка и бонусы всегда пересчитываются бэкендом.
  Промокод и бонусы применяются к первой позиции заказа, потому что сервер считает скидку на один заказ.
  При частичном отказе повторная отправка не дублирует уже созданные позиции: из корзины удаляются только успешные.
- **Заказы и доставка** — история заказов и статус отправления (сервис отслеживания).
- **Бонусы** — уровень, баллы и расчёт кэшбэка (сервис лояльности).
- **Акции** — список промокодов с мгновенным применением в корзину.
- **Аналитика** — сводка, воронка и последние события из сервиса аналитики.
- **Уведомления** — история писем сервиса уведомлений с фильтром по вашей почте.
- **Недавно просмотренные** — локальная история товаров и похожие товары в карточке.
- **О приложении** — версия, адрес API, ссылки и данные разработчика.
- **Состояние сервисов** — 10 параллельных health-проверок микросервисов со временем отклика. Доступно из профиля даже без входа.
- **Профиль** — вход/регистрация; роль и скидка приходят с сервера, пароль на устройстве не сохраняется.

## Запуск

Из корня проекта поднимите бэкенд:

```powershell
docker compose up -d --build
```

Затем в каталоге `mobile`:

```powershell
npm.cmd install
npm.cmd start
```

Дальше можно открыть:

- Expo Go — по QR-коду из терминала;
- Android-эмулятор — клавиша `a`;
- iOS-симулятор — клавиша `i` (только macOS);
- браузер — клавиша `w` (Expo Web).

Отдельные команды:

```powershell
npm.cmd run android
npm.cmd run ios
npm.cmd run web
npm.cmd run lint
npm.cmd run build:web
```

Веб-сборку можно проверить локально:

```powershell
npx.cmd --yes serve@14 dist -l 19007
```

Откройте <http://127.0.0.1:19007> и зайдите в **Профиль → Состояние сервисов**.

## Подключение к API

По умолчанию приложение стучится на `http://localhost` — этого хватает для Expo Web или эмулятора iOS.
Для **реального Android-устройства** или Android-эмулятора нужно указать IP компьютера, на котором запущен Docker:

```powershell
$env:EXPO_PUBLIC_API_ORIGIN = "http://192.168.1.10"
npm.cmd start
```

IP можно узнать командой `ipconfig` (параметр **IPv4-адрес**). Устройство должно быть в той же Wi-Fi-сети, а брандмауэр Windows — разрешать входящие подключения к порту 80.

Адрес можно также зафиксировать в `app.json` → `expo.extra.apiOrigin`.

Для публикации можно указать публичный HTTPS-адрес из раздела «Публикация в интернет» корневого `README.md` — например, временный Cloudflare Tunnel или домен на VPS. На реальном Android необходимо указать доступный извне адрес: `localhost` на устройстве указывает на само устройство, а не на ваш компьютер с Docker.

## Структура

```text
mobile/
├── App.jsx                     # провайдеры, шрифты, StatusBar
├── index.js                    # точка входа Expo
├── app.json                    # конфигурация приложения
├── src/
│   ├── api.js                  # HTTP-клиент и методы всех сервисов
│   ├── config.js               # API_ORIGIN, endpoints, промокоды
│   ├── theme.js                # цвета и шрифты как на сайте
│   ├── context/                # AuthContext, CartContext
│   ├── navigation/             # табы и стек-экраны
│   ├── components/             # дизайн-система и карточка товара
│   └── screens/                # экраны приложения
└── assets/icon.png             # иконка приложения
```

- Вотермарка «Разработка сайта: Притчин Владимир, группа 9-прг401» сохранена в профиле приложения.
- Приложение не хранит пароль и не доверяет клиентской цене — все деньги считает бэкенд.
